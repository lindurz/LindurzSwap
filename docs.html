Lindurz Documentation

Complete guide to Lindurz The Decentralized Edge

Overview

Lindurz is a decentralized exchange supporting multiple blockchain networks including Ronin, Berachain, and Monad.

🚀 Current Status: Lindurz is live on multiple testnets with mainnet launch coming soon.

Supported Chains

🎮 Ronin 🐻 Berachain ⚡ Monad

System Architecture

📚 Core Contracts

Router: Handles all swap operations and routing logic

Factory: Creates and manages trading pairs

Pair: Manages liquidity pools and token pairs

🔄 Swap Mechanism

Constant product formula (x*y=k) with 0.3% trading fees

API Reference

🌐 API Base URL

https://api.lindurz.xyz/v1

Endpoints

💰 Get Token Price

GET /price/:chain/:tokenAddress Example: GET /price/ronin/0x0b7007c13325c48911f73a2dad5fa5dcbf808adc Response: { "price": "1.00", "currency": "USD", "chain": "ronin" }

🏊 Get Pool Info

GET /pools/:chain Example: GET /pools/ronin Response: { "pools": [ { "pair": "RON/USDC", "address": "0x...", "tvl": "1000000", "volume24h": "50000" } ] }

Adding Liquidity

📈 Step-by-Step Guide

1. Connect your wallet to Lindurz

2. Navigate to the Liquidity section

3. Select the token pair you want to provide liquidity for

4. Enter the amount for each token

5. Approve the tokens and confirm the transaction

6. Receive LP tokens representing your share of the pool
